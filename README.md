Thirteen years of waiting, and the only cure is 200 hours of GTA VI. This meme is a doctor's note on a desk — stethoscope, game controller, coffee, and a calendar with 19 November circled — diagnosing "Leonida Fever" and prescribing "GTA VI — 200 hours, no work". The make.fun ghost stands beside the note as the doctor on duty, holding its magenta coin. The meme is `meme.png` in this repository; the X post carrying it is named in `POST.json`.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, standard library only, no network) copies `POST.json` to the output directory (`$MAKEFUN_OUTPUT_DIR`, or `/output` by default). Update `POST.json` with the real address of the X post before submitting.
